# Reinforcement Learning

A collection of Reinforcement Learning algorithms implemented from scratch in Python, with mathematical explanations, visualizations, and experiments.

---

## Overview

This repository contains educational implementations of fundamental Reinforcement Learning algorithms. The goal is to build an intuitive understanding of RL by implementing algorithms from scratch rather than relying on high-level libraries.

Topics range from classical **Multi-Armed Bandits** to modern **Deep Reinforcement Learning** methods.

---

## Topics Covered

- 🎰 Multi-Armed Bandits
- 🔍 Exploration vs Exploitation
- 🧠 Markov Decision Processes (MDPs)
- 📐 Dynamic Programming
- 🎲 Monte Carlo Methods
- ⚡ Temporal Difference Learning
- 🎯 SARSA
- 🤖 Q-Learning
- 🧩 Deep Q Networks (DQN)
- 📈 Policy Gradient Methods
- 🎭 Actor-Critic Algorithms

---

## Objectives

- Implement algorithms from scratch
- Explain the mathematical foundations
- Visualize learning behaviour
- Compare different RL techniques
- Build a solid understanding of modern Reinforcement Learning
